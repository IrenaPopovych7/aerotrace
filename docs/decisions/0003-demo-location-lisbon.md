# 0003 — Demo location: Parque das Nações, Lisbon

Status: Accepted (2026-11-08)

## Decision

Seed missions and the default map centre use Parque das Nações, Lisbon (`38.7685, -9.0930`), next to the
Web Summit venue, so the audience recognises the place.

## Consequences

The area is in controlled airspace near Lisbon airport. The app and docs state that this is simulation only.
